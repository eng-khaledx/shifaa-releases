## التسطيب | Install
1. نزّل **`ShifaaClinic-x.y.z.exe`** من آخر إصدار في [Releases](../../releases/latest).
2. افتحه واضغط **Yes**. لو ويندوز عرض "Windows protected your PC"، اضغط **More info ← Run anyway**.
3. اتبع شاشة الإعداد الأول اللي هتفتح في المتصفح.

بعد التسطيب البرنامج **بيحدّث نفسه لوحده**. كل تحديث موقّع رقميًا، والبرنامج بيرفض أي ملف مش موقّع من البائع.
